## 2. 10/20 にチームで決めたこと(サーバーに影響する分)

| 決定 | サーバーで必要になること |
|---|---|
| **指示コード表を v1 に入れる**(本部 → 現場の指示を、番号で送る) | 10/16 に外した「指示」を戻す。`messages` とは別に、指示(code + param)を保存・送信する。トピック `reray/v1/down/{id}/instruct`、`reray/v1/down/all/instruct`(案)。JSON は `{"v":1,"type":"instruct","src":"pc","dst":"all","seq":8,"mid":13,"ts":...,"code":2,"param":3}`(案) |
| **ポジション番号(1〜N)を動的に決める**。名前と場所は本部の画面で変える | ポジション表(番号、名前、説明)の DB 表と API(一覧・追加・変更)。指示の `param` と、定型信号の `pos` がこの番号を指す |
| 定型信号に「今いるポジション」を添える | `signal` に `pos`(任意、0 = 未指定)を足す。保存して一覧に出す |
| 定型信号は 4 つに限らず必要なぶん | コードを数値のまま保存する今の方針で問題なし(名前は画面側の表)。LoRa 側の上限は 31 |
| **平時の文字起こしを今期に入れる** | スマホ/PC のアプリが `POST /api/messages` に文字を送る。サーバーの変更はなし(送信者を区別したいなら `src` に端末 ID 以外を許す必要があるので、要相談) |
| 出口は今期 Wi-Fi(テザリング)。SIM は展望 | 構成図の「SIM あり」を「Wi-Fi」に読み替え |
| LoRa の実機作業は後回し(T-Beam 未着) | M5(実機結合)の前に、まず Wi-Fi 端末としての T-Beam でつなぐ |

正式な形(項目名・トピック名)は**共通仕様に書いてから**使います。上の JSON は案です。

## 3. 仕様修正案(10/16)への、ハード側の回答

README §8.2 と ARCHITECTURE §11-1 の 5 点について、ハード側で困るものはありません。

| 修正案 | ハード側 |
|---|---|
| text に `mid`、ack に `ack_mid` | **賛成。** LoRa の指示フレームには `mid` を載せる余地がないが、出口が「pc の seq → mid」を覚えておき、現場から返ってきた確認(seq 参照)を `ack_mid` に直して MQTT に出せる |
| `online` はサーバーだけが更新。判定時間 90 秒 / 15 分 | **賛成。** 端末側は何もしない |
| LoRa 端末の心拍(5 分おき)を出口が status に直す | **賛成。** 出口が送れる項目は `battery`(%)、`via: "lora"`、必要なら RSSI。**項目名は共通仕様で決めてほしい**(`glass` は LoRa 経由では分からないので省く) |
| `(device_id, seq)` に一意制約を付けない | 問題なし |
| LoRa 状態の端末には text が届かない(v1) | **賛成。** 代わりに指示コードが LoRa で届く(§2) |

seq の始まりを乱数にする案も、端末側は対応できます(受信側は回り込み前提で作ってあります)。

## 4. 出口(ハード)がサーバーに送るもの

出口は、LoRa で受け取ったものを次の形で MQTT に出します(`tkitora/re-ray` の `firmware/shared/include/reray/gateway.h`、PC 上でテスト済み)。

```json
{"v":1,"type":"signal","src":"dev-001","seq":42,"ts":1791849600,"code":2,"via":"lora"}
```

- 追加項目 `x`(区域=ポジション、人数区分、GPS 有無、RSSI、SNR)を付けられます。INTERFACES §2.2 のとおり**無視して構いません**。不要なら出さない設定にします。
- `ts` は端末の GPS 時刻。未同期のときは 0 ではなく出口の時刻を入れます。サーバーの受信時刻を正とする方針に賛成です。
- MQTT の `ack` に出すのは「指示を受け取った」だけ。LoRa 内部の確認(近くに届いた・本部に届いた)は出しません。
- 出口が複数あるときの識別(ARCHITECTURE §11-3)は、ハード側も未決です。検証は出口 1 台で進めます。
