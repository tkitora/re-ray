# COMPLIANCE — 技適・規制のチェックリスト(S0)

**このチェックが終わるまで、LoRa の電波を出さない。** `RERAY_TX_ENABLE=1` のビルドは、下の「ユーザー確認欄」が全て埋まってから。
この文書は資料から読み取った内容の整理であり、法的な判断ではない。判断に迷う点は、総務省(総合通信局)または販売元に確認すること。

## 1. 確認できている事実

### T-Beam の MIC 証明書(LILYGO の認証ページで公開されている PDF)

| 項目 | 内容 |
|---|---|
| 証明書の種類 | JAPAN MIC CERTIFICATE OF TYPE APPROVAL (Radio) |
| 証明書番号 | 211-231007 |
| 登録証明機関 | Bay Area Compliance Laboratories Corp.(RCB ID: 211) |
| 型式 | **T-BEAM-AXP2101-V1.2** |
| 発行日 | 2023-11-30 |
| 設備の区分 | 特定小電力無線(第2条第1項第8号)、2.4GHz帯の小電力データ通信システム(第19号、19-2号) |
| 920MHz 帯 | F1D、**920.6〜928MHz(200kHz、38ch)、アンテナ端子出力 16mW** |
| アンテナ | UHF:**外付けSMAアンテナ 2.0dBi**、Bluetooth/Wi-Fi:PIFAアンテナ 0.37dBi |
| 適用基準 | MIC Notices No. 88 Annex 1, 22, 43 & 44 |

### 読み取れること / 読み取れないこと

- 読み取れる:この型式の機器が、上の条件で認証されている。
- **読み取れない:** キャリアセンス、送信時間、休止時間、1時間あたりの総送信時間などの**動作条件を、どのファームウェアで満たすか**。自分のソフトで使う場合、これらは自分で守る必要があると考えること。
- **読み取れない:** 販売されている個体が、この証明書の型式と一致しているか(V1.2 / AXP2101 であること)。

## 2. 設計上の制約(コードに反映する)

| 項目 | 制約 |
|---|---|
| 送信出力 | アンテナ端子で 16mW(約12dBm)以下。**コード上限 12dBm、初期設定 10dBm** |
| 周波数 | 920.6〜928.0MHz のうち、規格で使える**チャンネル**のみ(下の確認事項) |
| アンテナ | 付属の SMA アンテナ(2.0dBi 相当)。他のアンテナは、同種・同利得かを確認してから |
| 送信前 | キャリアセンスを行う |
| 送信時間 | 1回の送信時間の上限、送信後の休止時間、1時間あたりの総送信時間の上限を守る |

## 3. 規格(ARIB STD-T108)で確認する事項

資料では、次のような値を見かけたが、**現行の値かどうかは未確認**。規格本文で確認すること。

- 1回の送信は 4秒未満
- 送信後の休止は 50ms 超
- キャリアセンスのしきい値と時間
- 1時間あたりの送信時間の総和(36秒 = デューティ1% という値が資料にあったが、緩和案も併記されていた)
- 使用できるチャンネル(周波数)と帯域幅
