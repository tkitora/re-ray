# COMPLIANCE — 技適・規制のチェックリスト(S0)

**このチェックが終わるまで、LoRa の電波を出さない。** `RERAY_TX_ENABLE=1` のビルドは、下の「ユーザー確認欄」が全て埋まってから。

### 読み取れること / 読み取れないこと

- 読み取れる:この型式の機器が、上の条件で認証されている。
- **読み取れない:** キャリアセンス、送信時間、休止時間、1時間あたりの総送信時間などの**動作条件を、どのファームウェアで満たすか**。自分のソフトで使う場合、これらは自分で守る必要があると考えること。
- **読み取れない:** 販売されている個体が、この証明書の型式と一致しているか(V1.2 / AXP2101 であること)。

### 調査結果(2026-10-13、Claude による資料の整理。**確認欄 §4 は未記入のまま**)

法的な判断ではない。数値は一次資料に当たったが、**確認欄を埋める(=確認する)のはユーザー**。資料の版:ARIB STD-T108 1.5 版(2023-03-03、ARIB が英訳を無料公開。日本語原文は有料のため未読。食い違いは原文が優先)、無線設備規則 第49条の14(2026-07-30 施行版)、告示 平成元年郵政省告示第49号の総務省統合版(令和7年2月27日施行)。

**規格上の位置づけ(中出力型、20mW 以下、キャリアセンス要):**

| 項目 | 値 | 出典 |
|---|---|---|
| 周波数 | 920.5〜928.1MHz。単位チャネル 200kHz、中心周波数は 920.6MHz + 0.2MHz×n(〜928.0MHz)、ch24〜61 の 38 波。証明書の 920.6〜928MHz・38 波と一致 | 無線設備規則 第49条の14 第7号、ARIB 表3-11 |
| チャネル区分 | ch24〜32(920.6〜922.2)=パッシブ優先、ch33〜38(922.4〜923.4)=アクティブ優先、ch39〜61(923.6〜928.0) | ARIB 付録 §7 |
| 空中線電力 | 20mW 以下(許容偏差 +20%/−80%)。EIRP 16dBm 以下なら 250mW まで可。絶対利得 3dBi 以下 | ARIB §3.2.1、無線設備規則 第7号ロ |
| 私たちの設定 | 16mW(約12.04dBm)+ 2.0dBi は、EIRP 約 14dBm(**こちらの計算**。資料の値ではない) | — |
| キャリアセンス | しきい値 −80dBm(超えたら送らない)、受信時間 128µs 以上、帯域は送信チャネルの幅 | 告示49号 第三項2、ARIB §3.4.2 |

**食い違い(未解決):** ARIB 1.5 英訳は、128µs 方式で 1 回の送信が 200ms を超えると、休止を「送信時間の 10 倍以上」とする。総務省告示の統合版にはこの規定がなく、休止は 2ms。**対策:** 1 回を 200ms 以下に抑える(17 バイト・BW125・CR4/5 なら SF9 の約 165ms まで)。SF10 は 約 330ms なので、確認が済むまで使わない(RELAY_DESIGN §5 の方針どおり)。

**ファームの暫定値との関係:** `firmware/shared/include/reray/airtime.h` の既定値は、1 回 200ms 以下、1 時間 18 秒以下(上限 360 秒の 5%)、休止 100ms 以上。調査した上限の内側に収めてある(単体テストで確認)。当初の暫定値(1 回 1 秒)は 0.4 秒の上限を超えていたため、2026-10-13 に直した。

**LoRaWAN AS923-1(RP002-1.0.4):** 日本の数値は自分では定めず、ARIB STD-T108 に従うよう指示している。必須チャネルは 923.2 / 923.4MHz(ARIB の ch37 / ch38)、既定の最大 EIRP 16dBm、400ms の dwell time 制限。汎用表の「<1%」は日本の数値ではない。

**使うチャネルの候補(確定ではない。確認欄 #5 の判断材料):** 128µs 方式のキャリアセンスで足りる ch33 以上(922.4MHz 以上)に絞ると、5ms 方式を実装しなくて済む。ch37 / ch38(923.2 / 923.4MHz)は LoRaWAN の必須チャネルと同じ。ただしアクティブ優先の ch33〜38 と、ch39〜61 の使い分けは未検討。

**技適機器で自作ファームを使うこと(要相談):**
- 免許不要の条件は「適合表示無線設備のみを使用」(電波法 第4条第3号)。表示が付いた特定無線設備に変更の工事をした場合は、表示を除去する義務がある(第38条の7第4項)。違反は 50 万円以下の罰金(総務省 FAQ 回答 117)。
- **ユーザーが自分でファームを差し替えることが「変更の工事」に当たるか、総務省が直接述べた資料は確認できなかった。**
- 送信時間制限装置とキャリアセンスは認証対象の工事設計に含まれる(無線設備規則 第49条の14 第7号ニ)。T-Beam ではこれらをソフトで実現するため、**自作ファームが認証内容から外れないという保証はない**(これは調査した側の推測)。
- 判断は自分でせず、総合通信局または登録証明機関への確認が確実(§5)。

**確認できなかったこと:** ARIB の日本語原文、告示第42号の本文、LoRa BW125kHz での実測の占有帯域幅と隣接チャネル漏えい電力、純正でないファームに対する総務省の直接の見解。
